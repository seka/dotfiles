## 分割の確認

- [ ] 各 PR が一つの責務を完結させている
- [ ] 各 PR が単独でビルド・テスト可能である
- [ ] 先行 PR で追加する未使用 API に、具体的な利用目的と後続 PR がある
- [ ] 実装・利用側移行・不要コード削除を、独立レビューできる場合は分けた
- [ ] 細かくしすぎて独立した検証単位を失っていない
- [ ] 依存 PR の base とマージ順を明記した
- [ ] 各段階に必要なテスト・ドキュメントを含めた
